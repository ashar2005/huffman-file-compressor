Every file tool, one lossless compressor

Compress any file with Huffman coding, built from scratch in C++. It runs entirely in your browser, so your files are never uploaded.

Compress file

Shrink any file and download a .huf archive. Verified automatically.

⇱

Decompress .huf

Restore the exact original file from a .huf archive.

1

Count

Every byte value (0 to 255) is counted, so any file type works.

2

Build the tree

A custom min-heap merges the rarest bytes into a Huffman tree. Common bytes get short codes.

3

Pack the bits

Canonical codes are packed into bytes with a small header, and checked by decompressing again.
